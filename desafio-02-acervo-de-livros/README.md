# Desafio 02 - Consulta de Acervo de Livros

## Objetivo
Desenvolver um programa capaz de armazenar e consultar informações de um acervo de livros utilizando dicionários em Python.

## Descrição
O programa recebe uma lista de livros cadastrados, onde cada livro possui um título e um código único. Em seguida, é realizada a consulta de um título específico para retornar o código correspondente.
Caso o título informado não esteja presente no acervo, o programa exibe a mensagem:

```text
Livro nao encontrado
```

## Conceitos Utilizados
* Dicionários (`dict`)
* Estruturas de repetição (`for`)
* Estruturas condicionais (`if/else`)
* Manipulação de strings com `split()`
* Busca por chave em dicionários

## Como Executar
```bash
python main.py
```

## Aprendizados
Este desafio permitiu praticar o uso de dicionários para armazenamento e recuperação eficiente de dados por meio de chaves, simulando uma consulta simples em um sistema de acervo digital.
