# Desafio 04 - Cliente VIP

## Objetivo

Implementar uma classe `Cliente` em Python para representar dados de um cliente e verificar se ele pode ser classificado como VIP com base em seu saldo.

## Descrição

O programa cria um objeto da classe `Cliente` a partir de três informações fornecidas pelo usuário: nome, e-mail e saldo. Em seguida, verifica se o saldo do cliente é maior ou igual a 1000.
Se a condição for atendida, o programa imprime:

```text
VIP
```

Caso contrário, imprime:

```text
REGULAR
```

## Conceitos Utilizados

* Programação Orientada a Objetos (POO)
* Classes e objetos
* Método de instância
* Atributos de classe
* Estruturas condicionais
* Operadores relacionais

## Aprendizados

Este desafio permitiu praticar os fundamentos de Programação Orientada a Objetos em Python, com foco na criação de classes, instanciação de objetos e implementação de regras de negócio a partir de métodos.
