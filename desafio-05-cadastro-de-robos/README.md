# Desafio 05 - Cadastro de Robôs

## Objetivo

Implementar uma classe base `Robo` em Python para representar robôs e suas tarefas, exibindo suas informações de forma padronizada.

## Descrição

O programa recebe o nome de um robô e a tarefa que ele executa. Em seguida, cria um objeto da classe `Robo` e retorna uma descrição formatada no padrão:

```text
Robo [nome] executa [tarefa]
```

## Conceitos Utilizados

* Programação Orientada a Objetos (POO)
* Classes e objetos
* Método de instância
* Atributos de objeto
* Formatação de strings com f-string
* Estrutura principal com `main()`

## Aprendizados

Este desafio permitiu praticar a criação de classes simples em Python, reforçando conceitos de Programação Orientada a Objetos e organização de código para facilitar futuras extensões, como a criação de novos tipos de robôs.
