# Desafio 06 - Colaborador Analista

## Objetivo

Implementar uma classe abstrata para padronizar colaboradores e uma classe concreta `Analista`, aplicando conceitos de abstração em Python.

## Descrição

O programa define uma classe abstrata `Colaborador`, contendo o método abstrato `exibir_info()`. Em seguida, cria a classe `Analista`, que herda de `Colaborador` e implementa esse método para retornar as informações do analista no seguinte formato:

```text id="pqk98v"
Analista: [nome]
```

## Conceitos Utilizados

* Programação Orientada a Objetos (POO)
* Classes abstratas
* Herança
* Método abstrato
* Implementação de interface por contrato
* Formatação de strings com f-string

## Aprendizados

Este desafio permitiu praticar abstração e herança em Python, mostrando como definir um padrão de comportamento para diferentes tipos de objetos por meio de classes abstratas.
